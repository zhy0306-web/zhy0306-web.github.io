## ✨ 项目简介

本项目是面向 **漳州一中八年12班** 的校园班级交流论坛，采用 **液态玻璃（Glassmorphism）** 视觉风格 —— 半透明磨砂玻璃质感搭配渐变背景与柔和光影，同时支持深色 / 浅色双模式，并在移动端（含微信浏览器）做了完整适配。

- 🎨 液态玻璃风格 UI，深色 / 浅色主题一键切换
- 📱 完整移动端适配，含微信浏览器安全区域处理
- 💾 双数据模式：默认连接 Supabase 云数据库，连接失败时自动降级为 localStorage 本地存储
- 🧭 哈希路由，纯静态单页应用，无需后端即可运行
- 🔒 内置用户系统与管理员后台

## 🧭 页面路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `#/` | 首页 | 班级公告、数据统计、最新帖子 |
| `#/board` | 板块 | 按板块分类浏览帖子 |
| `#/explore` | 广场 | 全部帖子信息流 |
| `#/ranking` | 排行 | 同学活跃度排行榜 |
| `#/auth` | 登录 / 注册 | 用户认证 |
| `#/profile` | 个人中心 | 我的信息与发布 |
| `#/favorites` | 收藏 | 我收藏的帖子 |
| `#/history` | 历史 | 我浏览过的帖子 |
| `#/admin` | 管理后台 | 仅管理员可访问 |

## 🛠️ 技术栈

- **HTML / CSS / JavaScript** —— 原生三件套，零构建工具，开箱即用
- **Supabase** —— 云数据库（通过 CDN 引入，已预配置）
- **CSS 自定义属性** —— 主题切换与响应式适配
- **Hash Router** —— 自实现的轻量哈希路由，支持异步渲染

## 🚀 快速开始

### 方式一：本地服务器（推荐）

仓库根目录提供了 PowerShell 静态服务器，在仓库目录下运行：

```powershell
./server.ps1
```

启动后访问 <http://localhost:8080> 即可。

### 方式二：直接打开

直接双击 `index.html` 用浏览器打开也可运行（本地存储模式）。

> ⚠️ 以 `file://` 协议打开时，部分浏览器可能限制 localStorage 或 CDN 加载，推荐使用方式一。

## 💾 数据存储模式

项目采用 **双模式存储**，初始化时自动切换：

1. **云数据库模式（Supabase）** —— 默认。已在 [js/supabase.js](js/supabase.js) 中配置好 Supabase 地址与密钥，页面加载时自动连接 `profiles` 等数据表。
2. **本地存储模式（localStorage）** —— 当 Supabase 连接失败时自动降级，数据保存在浏览器本地，适合离线演示。

切换逻辑见 [js/store.js](js/store.js) 中的 `Store.init()`。

## 🎨 主题与适配

- **深色 / 浅色双模式**：点击右上角太阳 / 月亮图标切换，选择会持久化到 `localStorage`。
- **移动端适配**：包含移动端布局、触摸交互与安全区域处理。
- **微信浏览器适配**：自动检测微信环境，应用固定安全区域值，避免内容被顶部 / 底部栏遮挡。

## 🌐 部署

本项目为纯静态站点，可直接部署到任意静态托管平台：

- **GitHub Pages**：推送至仓库后，在 Settings → Pages 选择 `main` 分支即可。
- **Vercel / Netlify / Cloudflare Pages**：直接导入仓库，构建命令留空，发布目录为根目录。
